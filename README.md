## Funções do sistema

- cadastro;
- login;
- dashboard;
- cadastro de disciplinas;
- cadastro de tarefas;
- prazo;
- prioridade;
- status da tarefa;
- percentual de produtividade.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## Como executar

1. Instalar o Node.js.
2. Abrir o terminal na pasta do projeto.
3. Executar:

npm install

4. Depois executar:

npm start

5. Abrir no navegador:

http://localhost:3000
